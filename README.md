# gh-assets

Static stylesheets for the Golf Headcovers site, served through jsDelivr:

```
https://cdn.jsdelivr.net/gh/<user>/gh-assets@main/gh-ui.css
```

`gh-ui.css` holds the components we tweak often (buttons, small UI pieces).
Because jsDelivr serves it from the edge, an edit + push + purge reaches every
visitor in seconds and never touches the WordPress host.
